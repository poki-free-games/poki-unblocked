Easter Card Memory Deluxe

  • 無料
  • ダウンロード不要
  • スマホでも遊べる
  • ボード＆カードゲーム

§1ゲームについて

Easter Card Memory Deluxeは、カードをめくってイースターアイテムのペアを見つけるカードマッチングゲームです。カードをクリックして裏返し、見たものの位置を覚えて、アイテムをペアにしましょう。ボード上のすべてのカードをクリアすればレベルクリアです。

各レベルは前より難しくなり、プレイ中は制限時間が進みます。ボードが大きくなるにつれて位置を頭に留めておくプレッシャーがかかるので、最初は落ち着いてカードを一通り見る方が、速くクリックするよりたいてい上手くいきます。短いラウンドなので、休憩中に1レベルだけ遊んでやめるのも簡単です。

§2遊び方

  • マウスでカードをクリックして裏返します。
  • 各イースターアイテムの位置を覚え、2枚目のカードをクリックしてペアを狙います。
  • ボード上のすべてのカードを揃えてレベルをクリアします。
  • 制限時間内に終わらせましょう。
  • 新しいレベルは前より難しくなります。
