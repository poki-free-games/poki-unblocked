ボード＆カードゲーム

短い休憩にぴったりのカードゲーム：めくって、揃えて、覚えて、静かな数分があればソリティアをクリアしよう。

5個のゲームカテゴリー遊び方
  1. 01 Summer Cold Drinks Card Memory ボード＆カードゲーム マウスでカードをクリックして裏返します。. プレイ →
  2. 02 Virus Cards Memory ボード＆カードゲーム マウスでカードをクリックしてめくります。. プレイ →
  3. 03 Cars Card Memory ボード＆カードゲーム カードをクリックして裏返し、下にあるイースターアイテムを見ます。. プレイ →
  4. 04 Easter Card Memory Deluxe ボード＆カードゲーム マウスでカードをクリックして裏返します。. プレイ →
  5. 05 Solitaire Daily ボード＆カードゲーム 赤いカードは黒いカードの上に、黒いカードは赤いカードの上に置いて場を組み立てます。. プレイ →

この棚には、一度で遊び切れるカードゲームが並んでいます。ほとんどは記憶合わせゲームです。裏向きのカードが並んだグリッドから、一度に2枚ずつめくってペアを見つけます。必要なのは注意力で、運だけではありません。カードの位置を頭に留め、すでにめくったカードに気づき、時間が進んでいるからといって焦ってクリックしないことが大切です。ソリティアはまた別の力が求められます。盤面を2〜3手先まで読み、カードをいつ土台に上げ、いつ残すかを判断します。

軽めのペア探しと暖かい季節のテーマを楽しみたいなら、Summer Cold Drinks Card Memory から始めましょう。Virus Cards Memory は同じルールで、少し変わった絵柄のセットです。見慣れないマッチングを味わいたいときにぴったり。Solitaire Daily は1回分のディールにじっくり取り組めるので、チャイムが鳴るまでの休憩に向いています。Cars Card Memory と Easter Card Memory Deluxe は、同じルールで違う絵柄を楽しみたい人のためのラインナップです。
