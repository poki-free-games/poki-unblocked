Esta sección reúne juegos de cartas que puedes terminar de una sentada. La mayoría son de memoria: una cuadrícula de cartas boca abajo y volteas dos a la vez para encontrar parejas. La habilidad está en la atención, no solo en la suerte. Tienes que retener posiciones en la cabeza, fijarte en qué cartas ya volteaste y resistir la tentación de hacer clic rápido solo porque corre el reloj. El solitario pide algo distinto: leer el tablero con dos o tres jugadas de antemano y decidir cuándo subir una carta a la base y cuándo dejarla fuera.

Empieza con Summer Cold Drinks Card Memory si quieres un conjunto ligero de parejas y un tema veraniego. Virus Cards Memory es la misma idea con imágenes más curiosas, ideal cuando quieres que el emparejamiento se sienta menos familiar. Solitaire Daily te da un reparto para resolver, perfecto para una pausa que termina cuando suena el timbre. Cars Card Memory y Easter Card Memory Deluxe completan la selección para quien quiera otro tema visual con las mismas reglas.
