Summer Cold Drinks Card Memory

  • Gratis
  • Sin descargas
  • Funciona en móviles
  • Juegos de Mesa y Cartas

§1Sobre el juego

Summer Cold Drinks Card Memory es un juego de emparejar cartas en el que volteas cartas para encontrar parejas de bebidas frías. Haz clic en una carta para darle la vuelta, recuerda qué bebida muestra y luego haz clic en una segunda carta para buscar su pareja. Despeja todas las parejas del tablero para completar el nivel.

Cada nivel es más difícil que el anterior y tienes tiempo limitado para terminarlo. El tablero te obliga a retener posiciones en la cabeza mientras corre el reloj, así que un volteo equivocado te cuesta un momento que quizá no tengas. La pregunta que te deja el juego es hasta qué nivel puedes llegar.

§2Cómo jugar

  • Usa el ratón para hacer clic en una carta y darle la vuelta.
  • Haz clic en una segunda carta para intentar emparejar la bebida fría.
  • Las parejas emparejadas salen del tablero; las cartas sin pareja se vuelven a girar.
  • Empareja todas las cartas del tablero para completar el nivel.
  • Cada nivel es más difícil que el anterior y el tiempo es limitado.
