Настольные и карточные игры

На этой полке собраны карточные игры, которые можно закончить за один заход. Большинство из них — игры на память: сетка рубашкой вверх, и ты переворачиваешь по две карты, чтобы найти пары. Здесь важна внимательность, а не только удача. Нужно держать в голове позиции, замечать, какие карты уже открывал, и не кликать наугад только потому, что идёт время. Пасьянс требует другого: читать поле на два-три хода вперёд и решать, когда поднять карту в фундамент, а когда оставить её на месте.

Начни с Summer Cold Drinks Card Memory, если хочешь лёгкий набор пар и тёплую летнюю тему. Virus Cards Memory — та же идея, но с более необычными картинками, хорошо, когда хочется, чтобы совпадения были менее привычными. Solitaire Daily даёт одну раздачу, которую можно разобрать за перерыв, который заканчивается со звонком. Cars Card Memory и Easter Card Memory Deluxe дополняют набор для тех, кому нужна другая тема картинок по тем же правилам.
