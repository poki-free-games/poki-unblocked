Word Finding Puzzle Game

  • Gratuit
  • Sans téléchargement
  • Fonctionne sur téléphone
  • Jeux de mots

§1À propos du jeu

Word Finding Puzzle Game est un jeu de mots mêlés : une grille de lettres cache des mots que vous devez trouver. Faites glisser votre doigt sur les lettres pour marquer un mot, et continuez jusqu'à ce que la grille soit vidée.

Chaque manche est une chasse. Les mots sont disposés horizontalement, verticalement ou en diagonale, et peuvent se lire dans les deux sens, donc une ligne de lettres que vous survolez peut être celle qu'il vous faut. Vous faites glisser les lettres dans l'ordre pour valider le mot, puis passez au suivant. Les trouver tous demande de la patience et l'habitude de lire la grille dans les deux sens. Le jeu est conçu pour enrichir votre vocabulaire et faire travailler votre cerveau, et la recherche elle-même est un travail calme plutôt qu'une course.

§2Comment jouer

  • Faites glisser les lettres d'un mot pour le sélectionner.
  • Les mots peuvent être horizontaux, verticaux ou diagonaux.
  • Les mots peuvent se lire dans les deux sens.
  • Trouvez tous les mots cachés dans la grille pour terminer.
