Cars Card Memory

  • Gratuit
  • Sans téléchargement
  • Fonctionne sur téléphone
  • Jeux de société et de cartes

§1À propos du jeu

Cars Card Memory est un jeu de memory où vous retournez des cartes pour révéler des objets de Pâques, mémorisez l'emplacement de chacun et les associez par paires. Videz toutes les cartes du plateau pour terminer le niveau.

Chaque niveau est plus difficile que le précédent, et un minuteur limite votre temps. Vous cliquez sur une carte pour la retourner, puis sur une autre pour chercher sa paire. Deux cartes qui ne correspondent pas se retournent face cachée : le plateau récompense donc l'attention plus que la vitesse. Le nom parle de voitures, mais les images sont des objets de Pâques : observez ce qui apparaît vraiment plutôt que ce que vous attendez.

Le jeu tourne dans le navigateur et fonctionne sur téléphone. Les manches courtes s'intègrent facilement dans une pause, et le travail de mémoire l'empêche de ressembler à de la pure chance. La question finale est de savoir jusqu'où votre mémoire peut vous porter dans les niveaux.

§2Comment jouer

  • Cliquez sur une carte pour la retourner et voir l'objet de Pâques caché dessous.
  • Cliquez sur une deuxième carte pour tenter une paire.
  • Les paires trouvées restent visibles ; les cartes qui ne correspondent pas se retournent face cachée.
  • Videz toutes les cartes du plateau pour terminer le niveau.
  • Chaque niveau est plus difficile que le précédent, et le temps est limité.
  • Utilisez la souris pour jouer.
