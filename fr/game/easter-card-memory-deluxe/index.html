Easter Card Memory Deluxe

  • Gratuit
  • Sans téléchargement
  • Fonctionne sur téléphone
  • Jeux de société et de cartes

§1À propos du jeu

Easter Card Memory Deluxe est un jeu de memory où vous retournez des cartes pour trouver des paires d'objets de Pâques. Cliquez sur une carte pour la retourner, mémorisez la position de ce que vous avez vu et associez les objets par paires. Videz toutes les cartes du plateau pour terminer le niveau.

Chaque niveau est plus difficile que le précédent, et un temps limité s'écoule pendant que vous jouez. La pression vient du fait de devoir garder les positions en tête à mesure que le plateau s'agrandit : un premier passage calme sur les cartes vaut souvent mieux que des clics rapides. Les manches courtes permettent de jouer un niveau pendant une pause et de s'arrêter là.

§2Comment jouer

  • Utilisez la souris pour cliquer sur une carte et la retourner.
  • Mémorisez l'emplacement de chaque objet de Pâques, puis cliquez sur une deuxième carte pour tenter une paire.
  • Associez toutes les cartes du plateau pour terminer le niveau.
  • Terminez avant la fin du temps imparti.
  • Chaque nouveau niveau est plus difficile que le précédent.
