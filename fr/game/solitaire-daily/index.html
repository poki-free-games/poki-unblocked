Solitaire Daily

  • Gratuit
  • Sans téléchargement
  • Fonctionne sur téléphone
  • Jeux de société et de cartes

§1À propos du jeu

Solitaire Daily est un jeu de cartes où vous triez un paquet mélangé en quatre piles d'As, chacune allant de l'As au Roi. Vous construisez le tableau en plaçant les cartes rouges sur les noires et les noires sur les rouges, en découvrant les cartes en dessous au fur et à mesure.

Les règles restent proches du solitaire classique. Quand aucun mouvement n'est possible sur le plateau, vous prenez une carte de la pioche pour ouvrir de nouvelles possibilités. La difficulté est d'anticiper : une carte que vous enterrez maintenant peut être celle dont vous aurez besoin plus tard, et les piles d'As n'acceptent les cartes que dans l'ordre. Un meilleur score est enregistré, pour que les parties répétées aient un objectif à mesurer. Chaque session est une donne unique que vous pouvez résoudre à votre rythme.

§2Comment jouer

  • Placez les cartes rouges sur les noires et les noires sur les rouges pour construire le tableau.
  • Déplacez les cartes vers les piles d'As dans l'ordre, de l'As au Roi, pour gagner.
  • Bloqué ? Prenez une carte de la pioche pour ouvrir de nouvelles possibilités.
  • Videz le tableau et complétez les quatre piles d'As pour terminer la partie.
