Virus Cards Memory

  • Gratuit
  • Sans téléchargement
  • Fonctionne sur téléphone
  • Jeux de société et de cartes

§1À propos du jeu

Virus Cards Memory est un jeu de cartes à associer où vous retournez des cartes pour trouver des paires de virus. Chaque niveau vous donne un plateau de cartes face cachée, et vous cliquez sur deux cartes à la fois pour les retourner. Une paire trouvée est retirée, et éliminer toutes les paires termine le niveau.

Les niveaux suivants sont plus difficiles que les premiers, et vous avez un temps limité pour finir chaque plateau. La mémoire et la rapidité comptent donc toutes les deux : un mauvais retournement vous coûte un moment, et le chrono continue de tourner. Les cartes sont des virus, donc les images se répètent d'une manière qu'il faut suivre attentivement. Vous jouez à la souris, et le jeu fonctionne sur téléphone.

§2Comment jouer

  • Cliquez sur une carte avec la souris pour la retourner.
  • Retournez une deuxième carte pour chercher une paire de virus identique.
  • Éliminez toutes les paires du plateau pour terminer le niveau.
  • Terminez avant la fin du temps imparti.
