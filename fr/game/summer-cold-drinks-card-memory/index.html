Summer Cold Drinks Card Memory

  • Gratuit
  • Sans téléchargement
  • Fonctionne sur téléphone
  • Jeux de société et de cartes

§1À propos du jeu

Summer Cold Drinks Card Memory est un jeu de memory où tu retournes des cartes pour trouver des paires de boissons fraîches. Clique sur une carte pour la retourner, mémorise la boisson affichée, puis clique sur une deuxième carte pour chercher sa paire. Élimine toutes les paires du plateau pour terminer le niveau.

Chaque niveau est plus difficile que le précédent, et tu as un temps limité pour finir. Le plateau te demande de retenir les positions pendant que le chrono tourne, donc un mauvais retournement te coûte un moment que tu n'as peut-être pas. La question que le jeu te laisse : jusqu'à quel niveau peux-tu aller ?

§2Comment jouer

  • Utilise la souris pour cliquer sur une carte et la retourner.
  • Clique sur une deuxième carte pour tenter d'associer la boisson fraîche.
  • Les paires trouvées quittent le plateau ; les cartes non associées se retournent.
  • Associe toutes les cartes du plateau pour terminer le niveau.
  • Chaque niveau est plus difficile que le précédent, et le temps est limité.
