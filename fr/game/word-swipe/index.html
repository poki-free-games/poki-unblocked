§1À propos du jeu

Word Swipe est un jeu de puzzle de mots basé sur le glissement de blocs de lettres et la lecture des couleurs des tuiles. Chaque niveau cache un mot, et ton rôle est de le trouver une supposition à la fois.

Une manche commence par un glissement : déplace les blocs sur les côtés pour former ta supposition. Ensuite, observe les couleurs. Un bloc jaune signifie que cette lettre est dans le mot mais à une autre place. Un bloc vert signifie que la lettre est déjà à sa place. Utilise ces indices pour réduire les possibilités et terminer le niveau. La liste de mots ne se limite pas à cinq lettres, donc des réponses plus longues apparaissent aussi.

La réflexion est posée et les couleurs rythment le jeu. Si tu aimes le Scrabble, les mots croisés ou les jeux de mots en général, ce jeu correspond à la même habitude.

§2Comment jouer

  • Fais glisser les blocs sur les côtés pour arranger ta supposition.
  • Observe la couleur de chaque bloc après une supposition.
  • Jaune signifie que la lettre est dans le mot.
  • Vert signifie que la lettre est à sa place.
  • Utilise les couleurs pour trouver le mot et terminer le niveau.
