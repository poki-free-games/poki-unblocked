Virus Cards Memory

  • Gratis
  • Ingen nedladdning
  • Fungerar på mobilen
  • Bräd- och kortspel

§1Om spelet

Virus Cards Memory är ett kortspel där du vänder kort för att hitta par av virus. Varje nivå ger dig en spelplan med nedvända kort, och du klickar på två åt gången för att vända dem. Ett par rensas när du hittar det, och när alla par är borta är nivån klar.

Senare nivåer är svårare än de tidigare, och du har begränsat med tid att klara varje spelplan. Det betyder att både minne och snabbhet spelar roll: ett felaktigt vänd kostar dig en stund, och klockan tickar hela tiden. Korten föreställer virus, så bilderna upprepas på sätt som du måste hålla koll på. Du spelar med musen, och spelet fungerar på telefoner.

§2Så spelar du

  • Klicka på ett kort med musen för att vända det.
  • Vänd ett andra kort för att leta efter ett matchande viruspar.
  • Rensa alla par på spelplanen för att klara nivån.
  • Bli klar innan tiden tar slut.
