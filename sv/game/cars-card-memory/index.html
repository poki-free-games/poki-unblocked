Cars Card Memory

  • Gratis
  • Ingen nedladdning
  • Fungerar på mobilen
  • Bräd- och kortspel

§1Om spelet

Cars Card Memory är ett kortmatchningsspel där du vänder kort för att avslöja påskföremål, komma ihåg var varje ligger och para ihop dem. Rensa alla kort på brädet för att klara nivån.

Varje nivå är svårare än den förra, och en timer begränsar din tid. Du klickar på ett kort för att vända det och sedan på ett annat för att leta efter dess matchning. Två kort som inte matchar vänds tillbaka med baksidan upp, så brädet belönar uppmärksamhet mer än snabbhet. Namnet säger bilar, men bilderna är påskföremål, så håll koll på vad som faktiskt dyker upp snarare än vad du förväntar dig.

Det körs i webbläsaren och fungerar på telefoner. Korta omgångar gör det lätt att passa in i en paus, och minnesarbetet gör att det inte känns som ren tur. Frågan i slutet är hur långt upp i nivåerna ditt minne kan bära dig.

§2Så spelar du

  • Klicka på ett kort för att vända det och se påskföremålet under.
  • Klicka på ett andra kort för att försöka få ett par.
  • Matchade par stannar borta; kort som inte matchar vänds tillbaka.
  • Rensa alla kort på brädet för att klara nivån.
  • Varje nivå är svårare än den förra, och klockan är begränsad.
  • Använd musen för att spela.
