Bräd- och kortspel

Kortspel för en kort paus: vänd, matcha, minns och lös en patiens när du har några lugna minuter.

5 spelKategorierSå spelar du
  1. 01 Summer Cold Drinks Card Memory Bräd- och kortspel Använd musen för att klicka på ett kort och vända det. Spela →
  2. 02 Virus Cards Memory Bräd- och kortspel Klicka på ett kort med musen för att vända det. Spela →
  3. 03 Cars Card Memory Bräd- och kortspel Klicka på ett kort för att vända det och se påskföremålet under. Spela →
  4. 04 Easter Card Memory Deluxe Bräd- och kortspel Använd musen för att klicka på ett kort och vända det. Spela →
  5. 05 Solitaire Daily Bräd- och kortspel Lägg röda kort på svarta kort och svarta kort på röda för att bygga spelplanen. Spela →

Den här hyllan rymmer kortspel du kan spela klart i ett svep. De flesta är minnesspel: ett rutnät med nedvända kort, och du vänder två åt gången för att hitta par. Det gäller uppmärksamhet, inte bara tur. Du måste hålla positioner i huvudet, lägga märke till vilka kort du redan vänt och låta bli att klicka snabbt bara för att klockan går. Patiens kräver något annat: att läsa brädet två eller tre drag framåt och avgöra när ett kort ska upp till grunden och när det ska ligga kvar.

Börja med Summer Cold Drinks Card Memory om du vill ha en lätt uppsättning par med sommartema. Virus Cards Memory är samma idé med en annorlunda bilduppsättning, bra när du vill att matchningen ska kännas mindre bekant. Solitaire Daily ger dig en giv att jobba igenom, perfekt för en paus som tar slut när det ringer. Cars Card Memory och Easter Card Memory Deluxe kompletterar setet för dig som vill ha ett annat bildtema med samma regler.
