Op deze plank staan kaartspellen die je in één keer kunt uitspelen. De meeste zijn memoryspellen: een raster met omgedraaide kaarten en je draait er steeds twee om om paren te vinden. Het draait om aandacht, niet alleen om geluk. Je moet posities in je hoofd houden, onthouden welke kaarten je al hebt omgedraaid en niet te snel klikken alleen omdat de klok loopt. Solitaire vraagt iets anders: het bord twee of drie zetten vooruit lezen en beslissen wanneer je een kaart naar de foundation verplaatst en wanneer je hem laat liggen.

Begin met Summer Cold Drinks Card Memory als je een lichte set paren en een zomers thema wilt. Virus Cards Memory is hetzelfde idee met een vreemdere set plaatjes, fijn als je wilt dat het matchen minder vertrouwd aanvoelt. Solitaire Daily geeft je één deal om door te werken, ideaal voor een pauze die eindigt als de bel gaat. Cars Card Memory en Easter Card Memory Deluxe maken de set compleet voor wie een ander plaatjesthema wil bij dezelfde regels.
