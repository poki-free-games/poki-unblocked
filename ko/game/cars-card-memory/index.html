§1게임 소개

카즈 카드 메모리는 카드를 뒤집어 이스터 아이템을 공개하고 각 아이템의 위치를 기억해 짝을 맞추는 카드 매칭 게임입니다. 보드의 모든 카드를 없애면 레벨이 완료됩니다.

레벨이 올라갈수록 난이도가 높아지고 타이머가 시간을 제한합니다. 카드를 클릭해 뒤집은 뒤 다른 카드를 클릭해 짝을 찾으세요. 짝이 맞지 않는 두 카드는 다시 뒤집히므로 보드는 속도보다 집중력을 요구합니다. 이름은 자동차지만 그림은 이스터 아이템이니 예상보다 실제로 나타나는 것에 주의하세요.

브라우저에서 실행되며 휴대폰에서도 작동합니다. 짧은 라운드라 휴식 시간에 맞추기 쉽고, 기억력 게임이라 단순한 운으로 느껴지지 않습니다. 마지막 질문은 당신의 기억력이 어디까지 레벨을 올릴 수 있느냐입니다.

§2플레이 방법

  • 카드를 클릭해 뒤집고 아래에 있는 이스터 아이템을 확인하세요.
  • 두 번째 카드를 클릭해 짝을 시도하세요.
  • 맞춘 짝은 그대로 사라지고, 맞지 않은 카드는 다시 뒤집힙니다.
  • 보드의 모든 카드를 없애면 레벨이 완료됩니다.
  • 새 레벨은 이전보다 어렵고 시간 제한이 있습니다.
  • 마우스로 플레이하세요.
