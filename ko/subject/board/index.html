보드 & 카드 게임

짧은 휴식에 즐기는 카드 게임: 뒤집고, 맞추고, 기억하며, 조용한 몇 분 동안 솔리테어 한 판을 정리해 보세요.

게임 5개카테고리플레이 방법
  1. 01 Summer Cold Drinks Card Memory 보드 & 카드 게임 마우스로 카드를 클릭해 뒤집으세요. 플레이 →
  2. 02 Virus Cards Memory 보드 & 카드 게임 마우스로 카드를 클릭해 뒤집으세요. 플레이 →
  3. 03 Cars Card Memory 보드 & 카드 게임 카드를 클릭해 뒤집고 아래에 있는 이스터 아이템을 확인하세요. 플레이 →
  4. 04 Easter Card Memory Deluxe 보드 & 카드 게임 마우스로 카드를 클릭해 뒤집으세요. 플레이 →
  5. 05 Solitaire Daily 보드 & 카드 게임 빨간 카드를 검은 카드 위에, 검은 카드를 빨간 카드 위에 놓아 테이블을 만드세요. 플레이 →

이 코너에는 한 번에 끝낼 수 있는 카드 게임이 모여 있습니다. 대부분은 기억력 맞추기 게임으로, 뒷면이 보이는 카드 그리드에서 한 번에 두 장씩 뒤집어 짝을 찾습니다. 필요한 능력은 집중력이지 운만은 아닙니다. 카드 위치를 머릿속에 기억하고, 이미 뒤집었던 카드를 알아채며, 시간이 흐른다고 해서 무작정 빨리 클릭하지 않아야 합니다. 솔리테어는 다른 능력을 요구합니다. 보드에서 두세 수 앞을 읽고, 카드를 기초 더미로 올릴 때와 그대로 둘 때를 판단해야 합니다.

가볍게 짝을 맞추고 싶다면 따뜻한 분위기의 Summer Cold Drinks Card Memory로 시작해 보세요. Virus Cards Memory는 같은 방식이지만 그림이 더 낯설어서, 익숙하지 않은 매칭을 원할 때 좋습니다. Solitaire Daily는 한 판을 차분히 풀어볼 수 있어 종이 울리면 끝나는 휴식 시간에 잘 맞습니다. Cars Card Memory와 Easter Card Memory Deluxe는 같은 규칙에 다른 그림 테마를 원하는 분들을 위해 준비했습니다.
